# Sarthak's Portfolio - DevOps Engineer

A modern, high-performance portfolio website demonstrating DevOps and Cloud Engineering expertise through its implementation.

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Vercel

## 🏗️ Architecture

```
Infrastructure, but beautiful.
Gumroad × Linear × Vercel × Terminal
```

## 📦 Project Structure

```
sarthaks/
├── app/                    # Next.js app directory
│   ├── components/         # React components (modular)
│   ├── data/              # Static data and configuration
│   ├── hooks/             # Custom React hooks
│   ├── utils/             # Utility functions
│   └── page.tsx           # Main page
├── public/                # Static assets
└── styles/                # Global styles
```

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 🎨 Design Philosophy

- **Minimal:** Clean, editorial design with generous whitespace
- **Premium:** High-quality typography and subtle interactions
- **Technical:** Demonstrates DevOps through implementation
- **Performant:** Fast loading across all platforms
- **Responsive:** Mobile-first, works beautifully everywhere

## 🚢 Deployment

Automated deployment pipeline:
- Push to GitHub → GitHub Actions → Build & Test → Deploy to Vercel
